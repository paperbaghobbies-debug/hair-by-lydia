# Hair by Lydia

Lydia Hair is a modern, responsive web application designed as a digital portfolio and client booking showcase for a professional hair stylist. Built using semantic HTML5, CSS3, and vanilla JavaScript, the project presents a curated gallery of transformation work, detailed service menus, and an interactive booking inquiry interface. The platform focuses on high-performance visual presentation, mobile-first responsiveness, and intuitive navigation to convert casual visitors into client appointments.
